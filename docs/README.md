# 项目文档

本目录保存 MimirTalk WebUI 从解包准备、主体开发、编辑栏改造、气泡九宫格修正、
字体修复到最终清理的完整记录。

## 目录

| 路径 | 内容 |
| --- | --- |
| `DEVELOPMENT.md` | 完整开发日志，按时间线整理 |
| `ARCHIVE_MANIFEST.json` | 归档文件来源、大小与 SHA256 校验清单 |
| `unpack/` | 游戏资源解包流程文档 |
| `guides/` | 各专项说明：需求记录、代码审计、交接文档、提取流程 |
| `reports/` | 联系人、素材、气泡与资源索引报告 |
| `screenshots/final/` | 最终界面与关键功能验证截图 |
| `data-backup/` | 清理前的数据快照与清单 |
| `legacy-tools/` | 已归档的一次性脚本、旧字体子集与旧样式备份 |

## 说明

- 文档中出现的 `mimirtalk_webui/` 路径对应仓库当前的 `webui/` 目录。
- `ARCHIVE_MANIFEST.json` 记录的是整理阶段的工作区路径，其中的 `生成物/`、
  `文档/` 等目录在仓库中已分别映射为 `reports/`、`screenshots/`、`guides/`。
- 历史迭代过程中的中间截图未纳入仓库，仅保留最终验证截图。
